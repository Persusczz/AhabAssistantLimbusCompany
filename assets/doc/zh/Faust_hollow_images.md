# 空洞预设图片采集与接入

已收到并转换 5 张原生游戏截图，原图保持不变。已核对空洞菜单图案和完整战斗画面中的 OVERCLOCK 标记，蓝色、金光技能图的觉醒/过载及悬停状态仍待用户确认；整局启动拦截保留。图片匹配不代表操作流程已经通过实机测试。

## 现有资源的实际形式

项目原文规范见[图片识别机制](image_recognition.md)。模板以 Steam 游戏客户区的 **2560×1440** 截图为基准，运行时按 `cfg.set_win_size / 1440` 缩放。菜单图片按 `default/dark` 主题和 `zh_cn/en/share` 语言分类。

| 示例 | 磁盘尺寸 | 形式与行为 |
| --- | --- | --- |
| `battle/turn_assets.png` | 2560×1440 | 除左上角 TURN 字样外均为黑底；非黑区域为 `(26,126)-(89,170)`，匹配器先裁出该区域，再在附近搜索 |
| `battle/turn_ocr_assets.png` | 2560×1440 | 非黑区域为 `(20,123)-(210,193)`，用于回合数 OCR 的裁切范围 |
| `battle/gear_left.png` | 30×26 | 仅核心小图，无 `_assets` 后缀；默认在整张截图中匹配 |
| `battle/gear_right.png` | 51×129 | 同为核心小图，用于定位技能栏 |
| `mirror/shop/level_IV_gifts/poise_level_IV.png` | 73×95 | 商店中止水的 UI 小图，用于库存识别；不是完整游戏立绘 |

`ImageUtils` 加载图片时会丢弃 alpha 并转为灰度。**透明背景不等于匹配遮罩**：需要保证可忽略部分的 RGB 为黑色。`_assets.png` 自动计算非黑 bbox；仅 `_bbox.png` 并不会自动触发同样的匹配裁切行为，调用方通常只读取它的 bbox。

觉醒与过载最终也会转成灰度，因此不能只依靠蓝、红颜色边框区分。应采集有结构差异的 UI 区域，再用交叉匹配验证；若两种状态同时命中，预设会停止。

保存无压缩改色、无网页播放器边框的原始 PNG 游戏截图，优先使用 2560×1440 客户区。保留整张原图，不必提前裁切。应包含以下状态：

1. 浮士德 EGO 菜单展开，觉醒空洞卡片可见。
2. 长按切换后的过载空洞菜单状态。
3. 觉醒空洞已选入技能栏、尚未开始交战。

5. 第四层浮士德和黑派良秀出战，良秀守备已选，并显示可拦截的敌方技能槽；另留一张完成拖拽拦截的画面用于验证。
6. 第五层二号线第二回合，空洞瞄准目标头部，并显示玫瑰两个部位的索敌标记；另留未索敌画面作为负样本。

截图前等待 UI 稳定，避开加载、技能播片、转场以及遮住目标的提示。数值、理智、消耗、伤害、回合数和敌人血量会变化，裁图时避开这些文字；包含文字的语言专属模板应放入对应语言目录，不能混用 `share`。

## 裁图与验证

离线脚本 `scripts/prepare_faust_hollow_image.py` 使用真实截图和明确选区生成核心模板，不启动游戏。命令参数如下；`LEFT TOP RIGHT BOTTOM` 必须换为在原图中核对过的像素坐标：

```text
python scripts/prepare_faust_hollow_image.py --source 游戏原图.png --name hollow_awakening --box LEFT TOP RIGHT BOTTOM
```

2560×1440 完整截图默认保持原比例。对于其他尺寸的原生截图或已经裁切的图片，必须明确指定经标定的 UI 比例；例如本次采集使用：

```text
python scripts/prepare_faust_hollow_image.py --source 原生裁片.png --name hollow_skill_gold --box LEFT TOP RIGHT BOTTOM --source-scale 0.75
```

脚本校验选区边界和比例，将透明像素合成到黑底，按 UI 比例缩放后输出 RGB PNG，拒绝缺少灰度细节的纯色选区，并避免覆盖已有模板。裁片尺寸本身不提供窗口比例，不指定比例会拒绝转换。比例参数也不能证明图片来自真实游戏，不应传入网页播放器画面。

补图后需验证：对应状态能命中；基础 EGO、相反 EGO 模式、普通技能、未索敌画面不能误命中；常用窗口分辨率下定位正确；良秀只拦截一个指定槽；二号线两部位均被索敌。当前图片阈值为 0.9；已用真实技能栏小样验证 OVERCLOCK 标记在 1080 和 1440 基准缩放下能命中，两个蓝色/金光图案不会误命中该标记。测试样本只截取游戏技能栏局部，存于 `tests/fixtures/faust_hollow/`。其他场景和动画帧仍待标定。

`scripts/image_similarity.py` 可离线分析模板间相似度；`scripts/match_steam_image.py` 会启动游戏，只在准备好实机验证时运行。不要因模板文件已经存在而移除草稿启动拦截：商店和特殊场景仍有未完成项。
