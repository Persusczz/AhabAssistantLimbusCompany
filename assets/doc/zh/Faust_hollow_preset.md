# 空洞浮士德预设（草稿）

此预设的目标是整局自动执行。当前已实现载入设置、保存和导入导出、分层主题包筛选及启动校验，尚不能自动刷完整一局。选择此预设后启动任务会在操作游戏前停止，并显示未完成项。

在“队伍设置”点击“空洞预设（草稿）”，查看设置后点击“保存”。载入会保留当前游戏内 TEAM 编号和历史统计，重置冲突的队伍选项。点击“停用预设”仅取消流程标记，保留当前队伍设置；保存后按普通镜牢设置执行。

配置源为 `assets/config/presets/faust_hollow.yaml`；也可通过原有“导入设置”读取。`preset_plan` 保存策略说明，实际队伍选项位于顶层。完整计划来自内置文件，队伍导出只保留实际设置和预设标记。

此草稿仅适用于包含预设启动校验的新源码；旧版 AALC 会忽略未知的预设字段，不能向旧版导入此文件。

## 已确认的流程

| 阶段 | 计划 |
| --- | --- |
| 准备 | 高速浮士德与四破空洞；星光只选第 1、3 项，关闭星光兑换经费；呼吸开局，优先烟斗 |
| 观测 | 盛宴款待、白线；视频 1:10 显示两件均为三级，菜单行列仍未展示 |
| 一层 | 赌徒包；建议顺手购买呼吸饰品 |
| 二层 | 地狱鸡；开始随缘买三级饰品 |
| 三层 | 色欲包，地狱鸡 Boss 封面；优先非集中遭遇战和事件，不可避免的精英二选一选小 Boss，第一回合磨刀、第二回合击杀 |
| 四层 | 憎恶与绝望；默认普通，可用现有“转困难楼层”设置选择第四层切换；准备四件四级饰品，升级美感、止水，恢复浮士德理智，换后备人格；黑派良秀守备拦截，浮士德觉醒空洞 |
| 五层 | 仅二号线，卸下良秀；第一回合觉醒空洞，第二回合瞄准头部，确保命中玫瑰两个部位 |

## 视频核对与待确认项

参考[原视频](https://www.youtube.com/watch?v=VkK2QSSOa7Q)：

- 0:55 讲解前三层采用 EGO 过载；精确操作尚未标定。
- 1:00 推荐开局第 1、3 项，1:05 显示烟斗优先，1:10 显示两件三级观测饰品。
- 1:32 展示止水和 Fragment of Conceit（呼吸残片），1:55 展示 Fragment of Friction（充能）和 Fragment of Decay（沉沦）；9:40 商店中同时有止水、呼吸残片和充能残片。视频的目标并不局限于原文“呼吸、沉沦四件”。按原文拟定的四件候选为止水、美感、Fragment of Conceit、Fragment of Decay，充能残片另作补强；仍待用户确认。实际目标暂保留两个空值。
- 视频写的是第五层切困难；本预设遵循用户要求，默认普通并允许现有设置选择第四层切困难。
- 视频中的第二回合操作与用户提供的觉醒空洞描述有差异，具体战斗实现须继续核对；当前不自动执行视频动作。

剩余工作：确认两件观测饰品的位置和四件合成目标，接入指定 EGO/过载、回合识别、单人守备拦截、第五层部位索敌、指定理智恢复、人格更换、四件饰品合成、第三层节点与苦难筛选，并完成实机验证。

目前的启动拦截由程序实现，手动把 YAML 的 `status` 改成 `ready` 也不会启用未完成的自动流程。
